安全建议

基础安全检查清单：
1. 管理页面仅内网访问（uhttpd绑定LAN口IP）
2. SSH修改默认端口 + 仅内网或密钥登录
3. 关闭不必要的服务（rpcbind/NFS/ttyd/wsdd2）
4. 防火墙默认拒绝WAN口入站
5. 端口转发只开放必要端口
6. 定期查看SSH登录日志，发现异常IP及时封禁
7. 建议安装fail2ban自动封禁爆破IP
8. 建议开启SSH密钥登录，禁用密码登录

关于插件

插件名称网络管理 (luci-app-netmanager)
版本v1.4.0
作者Network Manager
适配系统iStoreOS / OpenWrt (fw4/nftables)
功能模块系统概览 / 端口转发 / 规则管理 / SSH日志 / 访问日志
后端脚本/usr/sbin/netmanager
配置文件/etc/config/netmanager

卸载插件

⚠ 危险操作（不可撤销） 将删除后端脚本、LuCI页面、init/hotplug脚本、nft规则、cron任务与缓存；2秒后自动重启uhttpd。用户在 /etc/config/firewall 中的端口转发与防火墙规则不受影响。
卸载范围 不勾选则全删；勾选后下次重装可继承原配置
卸载后浏览器将自动跳转到首页，左侧菜单不再显示「网络管理」
